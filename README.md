Hangman is a classic word-guessing game where the player tries to uncover a hidden word one letter at a time.

-->You start with 6 lives (or more, depending on word length).

-->Each wrong guess reduces your remaining lives.

-->If you lose all your lives, you’ll get a final chance to guess the entire word at once.

-->Win by guessing the word before lives run out, or by correctly using your last-chance guess.

A simple, fun command-line game built entirely with Python’s random module and standard input/output.
